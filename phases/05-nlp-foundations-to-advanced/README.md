# Phase 5: NLP, Foundations to Advanced

> Ngôn ngữ là giao diện với trí thông minh. Làm chủ mọi tầng.

## Start this phase on GitHub

**Prerequisites:** Phase 2 Lesson 14, Naive Bayes. Python 3.11+ là đủ cho
bài học đầu tiên.

**Bài học đầu tiên:** [Xử lý văn bản](01-text-processing/)

Chạy lệnh này từ thư mục gốc của kho lưu trữ:

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

Giữ lại lệnh, mã thoát, danh sách token, các gốc từ, các dạng từ điển và một ví dụ mà
việc lấy gốc từ làm mất ý nghĩa nhưng việc đưa về dạng từ điển giữ nguyên ý nghĩa.

**Hành động tiếp theo:** Thêm một câu có dấu câu và một động từ bất quy tắc,
kiểm tra kết quả, rồi tiếp tục đến [Bag of Words và TF-IDF](02-bag-of-words-tfidf/).

Duyệt [danh sách bài học đầy đủ của Phase 5](../../README.md#phase-5) hoặc
[lộ trình xuyên các giai đoạn](../../ROADMAP.md).
