# Phase 16: Multi-Agent & Swarms

> Phối hợp, sự nổi lên, và trí thông minh tập thể.

## Start this phase on GitHub

**Prerequisites:** Giai đoạn 14 Kỹ thuật agent. Node.js 20+ và `npx` là
cần thiết cho demo TypeScript đầu tiên.

**Bài đầu tiên:** [Vì sao đa agent](01-why-multi-agent/)

Chạy lệnh này từ thư mục gốc kho mã:

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

Giữ lại lệnh, mã thoát, các tổng token và lệnh gọi công cụ của agent đơn lẻ và đa agent,
và một đánh đổi khiến phối hợp được thêm vào đáng giá.

**Hành động tiếp theo:** Thay đổi tác vụ, so sánh hai cách tiếp cận lần nữa, rồi
tiếp tục tới [Di sản FIPA-ACL và các hành vi ngôn ngữ](02-fipa-acl-heritage/).

Duyệt [toàn bộ danh sách bài học Giai đoạn 16](../../README.md#phase-16) hoặc
[lộ trình xuyên giai đoạn](../../ROADMAP.md).
