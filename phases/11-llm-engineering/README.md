# Phase 11: LLM Engineering

> Đưa LLM vào làm việc trong các ứng dụng sản xuất.

## Start this phase on GitHub

**Prerequisites:** Các Bài 01 đến 05 của Giai đoạn 10, hoặc kiến thức tương đương về
token hóa, pipeline dữ liệu, tiền huấn luyện và mở rộng quy mô.

**Bài học đầu tiên:** [Prompt Engineering](01-prompt-engineering/)

Chạy lệnh này từ thư mục gốc của kho mã:

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

Giữ lại lệnh, mã thoát, metadata của prompt được tạo, kết quả kiểm thử và một
thay đổi prompt cùng sự khác biệt đầu ra mà nó gây ra. Bản demo dùng các
phản hồi mô hình được mô phỏng và không cần khóa API.

**Hành động tiếp theo:** Giải thích biến prompt nào đã thay đổi hành vi và tại sao, rồi
tiếp tục đến [Few-Shot, Chain-of-Thought và Tree-of-Thought](02-few-shot-cot/).

Duyệt [danh sách đầy đủ các bài học Giai đoạn 11](../../README.md#phase-11) hoặc
[lộ trình xuyên giai đoạn](../../ROADMAP.md).
