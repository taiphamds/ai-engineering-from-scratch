## Start this phase on GitHub

**Prerequisites:** Phase 3 Deep Learning Core, Phase 5 Lesson 09 về
các mô hình sequence-to-sequence và Phase 5 Lesson 10 về attention.

**Bài học đầu tiên:** [Vì sao Transformer](01-why-transformers/)

Chạy lệnh này từ thư mục gốc của kho lưu trữ:

```bash
python3 phases/07-transformers-deep-dive/01-why-transformers/code/main.py
```

Giữ lại lệnh, mã thoát, bảng độ sâu nối tiếp và song song, kiểm tra tương đương
và một câu mô tả đánh đổi tốc độ-so-với-bộ nhớ.

**Hành động tiếp theo:** Giải thích vì sao độ sâu song song thay đổi câu chuyện phần cứng, rồi
tiếp tục đến [Self-Attention từ đầu](02-self-attention-from-scratch/).
