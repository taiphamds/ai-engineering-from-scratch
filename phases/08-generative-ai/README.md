# Phase 8: Generative AI

> Tạo ảnh, video, âm thanh, 3D và nhiều thứ khác.

## Start this phase on GitHub

**Prerequisites:** Giai đoạn 2 Nền tảng ML, Giai đoạn 3 Cốt lõi học sâu, và
Giai đoạn 7 Bài 14, Xây dựng một Transformer từ đầu.

**Bài học đầu tiên:** [Phân loại và lịch sử mô hình sinh](01-generative-models-taxonomy-history/)

Chạy lệnh này từ thư mục gốc của kho mã:

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

Giữ lại lệnh, mã thoát, các ước lượng mật độ, các mẫu được sinh và một
câu giải thích điều mà một bộ sinh ẩn không thể trả lời về `p(x)`.

**Hành động tiếp theo:** Thay đổi seed ngẫu nhiên, so sánh các ước lượng mật độ, rồi
tiếp tục đến [Autoencoder và VAE](02-autoencoders-vae/).

Duyệt [danh sách đầy đủ các bài học Giai đoạn 8](../../README.md#phase-8) hoặc
[lộ trình xuyên giai đoạn](../../ROADMAP.md).

15 bài học, tổng cộng khoảng 15 giờ. Mỗi bài học cung cấp một tài liệu chi tiết, một
bản demo Python có thể chạy, một sơ đồ và một skill có tên cho agent của bạn.
